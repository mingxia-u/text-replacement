# 文字替换助手

一个用于文档整理和批量文本替换的 Web 工具。

支持上传文档、解析内容、根据自定义替换规则批量处理文本，并生成整理后的结果。

项目基于 vinext starter 初始化，并根据文字替换场景进行了业务开发。

---

## 功能

### 文档处理

- 上传文档文件
- 自动解析文档内容
- 对文档内容进行批量替换
- 查看整理后的结果

### 替换词库

- 创建自定义替换规则
- 管理常用替换词
- 保存个人替换配置
- 快速应用替换规则

### 数据存储

- 替换规则保存在浏览器 LocalStorage
- 文档内容仅在当前浏览器环境处理
- 不上传用户文档数据
